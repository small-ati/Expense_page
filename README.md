\# 个人记账本自动化测试



\## 项目简介

这是一个独立完成的自动化测试项目，用于验证一个本地“个人记账本”页面的核心功能，包括添加支出、删除支出、总金额计算和异常输入处理。



\## 功能列表

\- 添加支出（项目名、金额、分类）

\- 删除支出

\- 总金额自动计算

\- 清空测试残留数据

\- 无效金额输入弹窗提示



\## 技术栈

\- Python 3

\- Selenium（WebDriverWait、Select、Alert）

\- pytest

\- POM（页面对象模型）：将页面元素定位和操作封装到独立的类中，使测试代码更清晰、更易维护

\- Git



\## 项目结构

\- `expense\_page.html`：被测试的本地页面

\- `expense\_obj.py`：POM 页面对象（定位和操作封装）

\- `test\_expense.py`：测试用例

\- `README.md`：项目说明



\## 如何运行

1\. 安装依赖：pip install selenium pytest

2\. 将匹配 Edge 版本的 msedgedriver.exe 放在项目文件夹

3\. 运行：pytest test\_expense.py -v
